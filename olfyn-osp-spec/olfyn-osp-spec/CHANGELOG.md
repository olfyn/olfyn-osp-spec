# Changelog

All notable changes to the OSP specification will be documented here.

## [1.0.0] — 2026-06-01

### Added
- Initial OSP v1.0 specification
- 10 aromatic dimensions model
- Full OSP Profile JSON schema
- OSP Session structure for therapeutic sequences
- REST API endpoint definitions
- WebSocket real-time control protocol
- Device Capabilities declaration format
- OLFYN DB public API specification
- Error codes E001–E010
- OSP Compatible certification requirements
- JSON Schema for profile validation
- Example profiles: Memory, Presence, Remembrance, General
